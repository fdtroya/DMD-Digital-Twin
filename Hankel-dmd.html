Hankel Dynamic Mode Decomposition with control for temperature diffusion monitoring

Author

Fernando Troya

Published

February 12, 2026

1. Introduction

Standard Dynamic Mode Decomposition (DMD) is a powerful tool for discovering coherent structures in high-dimensional data. However, when the observation dimension is low (e.g., a single sensor probe) or when the system exhibits standing waves, standard DMD may fail to capture the full dynamic.

Hankel DMD overcomes this by using time-delay embeddings. Instead of analyzing a single snapshot in time, time-delay embeddings are used to augment the dimension of the data. This enriches the state space, allowing us to capture dynamics that are unobservable in the original low-dimensional measurement.

In this application case we want to achieve a model that can predict the temperature raise of 2 switches based on the power loss, Time-delay embeddings of 2 temperature probes \([T1_n,T2_n]\) and power inputs, \([P1_n,P2_n]\) are stacked and phase lagged to run the DMDc (Dynamic Mode Decomposition with control) algorithm, proposed by (Proctor, Brunton, and Kutz 2014), and produce a state transition matrix M.

Additionally, an Online DMD algorithm was implemented as a monitoring tool as described in (Zhang et al. 2017)

2. Mathematical Formulation

The Hankel Matrix

Given a time series of data measurements \(\mathbf{x} = [x_k, x_{k+2}, \dots, x_N]\), where each \(x_k\) can be a scalar or a vector, we construct a Hankel matrix \(\mathcal{H}\).

In this application case \(x_k=[T1_k,T2_k]\)

If we choose a stacking depth (or lag embedding dimension) \(d\), the Hankel matrix arranges the data such that each column contains a trajectory of length \(d\):

\[ \mathcal{H_X} = \begin{bmatrix} x_{k} & x_{k+1} & \dots & x_{N} \\ x_{k-1} & x_{k} & \dots & x_{N-1} \\ \vdots & \vdots & \ddots & \vdots \\ x_{k-d} & x_{k-d+1} & \dots & x_{N-d+1} \end{bmatrix}_{d\times N-d} \]

The Omega Matrix

For DMDc we define a input snapshot matrix \(U_N=[u_k,u_{k+2},\dots, u_N]\) where each \(u_k\) can be a scalar or a vector. In this application \(u_k=[P1_k,P2_k]\) with a Hankel matrix \(\mathcal{H_U}\).

To obtain the augmented matrix \(\mathcal{\Omega}\) we construct

\[ \mathcal{\Omega} = \begin{bmatrix} \mathcal{H_X} \\ \mathcal{H_U} \end{bmatrix} \]

For the temperature rise modelling in this application 2 experiments \([A,B]\) are conducted with \(P_1=P, P_2=0\) and \(P_1=0, P_2=P\), in order to capture the effects of each source the Hankel matrix \(\mathcal{\Omega}=[\mathcal{\Omega_A} \mathcal{\Omega_B}]\) is assembled.

In DMD we want to compute a transition Matrix \(M\) such as \(X_{N}=\Omega_{N-1}M\), since in this problem we have inputs \(P_1,P_2\) the problem is formulated using DMDc \(Z_{N}=Z_{N-1}A +U_{N}B\)

The DMDc Algorithm

Once we have \(\mathcal{\Omega}\), we proceed with the standard DMD algorithm:

  1. Create two time-shifted matrices from \(\mathcal{H}\):

    • \(\Omega_{N-1} = \mathcal{\Omega}[k:N-1]\) (The past)
    • \(X_{N} = \mathcal{H_X}[k+1:N]\) (The future)

  2. Compute the Singular Value Decomposition (SVD) of \(\Omega_{N-1}\): \(\Omega_{N-1} \approx U \Sigma V^*\).

  3. Identify the most energetic modes in \(\Sigma\).

  4. Truncate matrices to new dimension e.g m dominant modes \(\tilde{U}=U[:,:m]\) \(\tilde{\Sigma}=\Sigma[:m]\) \(\tilde{V}^*=V^*[:m]\)

  5. Split \(\tilde{U}\) into the state \(U_x=\tilde{U}[:d\times states,:]\) and input components \(U_u=\tilde{U}[d\times states:,:]\)

  6. Project \(X_N\) into the reduced subspace \(U_x\) \(\tilde{X}_N=U^*_xX_N\)

  7. Compute the operator \(\tilde{M}\) that maps \(\Omega_{N-1}\) to the future \(X_{N}\): \[\tilde{M} = \tilde{U}^* \tilde{X}_N \tilde{V} \tilde{\Sigma}^{-1}\]

  8. Compute \(\tilde{A}=\tilde{M}\tilde{U}^*_x \tilde{U}_x\) ; \(\tilde{B}=\tilde{M}\tilde{U}^*_u\) and state \(\tilde{Z}_{N-1}=\tilde{U}^*_xX_{N-1}\)

  9. Compute the eigenvalues \(\lambda\) and eigenvectors \(W\) of \(\tilde{A}\).

  10. Diagonalize \(\tilde{A}_d=W^{-1}\tilde{A}W\); \(\tilde{B}_d=W^{-1}\tilde{B}\) and the new eigenbasis state \(\tilde{Z}_d=W^{-1}\tilde{Z}\)

3. Online DMD

For the real time monitoring of time constants in time varying systems, such as in the case of thermal wear/degradation, the online DMD algorithm is useful to update the \(\tilde{A}_d\) matrix at each time step, while using the offline DMD results as a healthy baseline.

Formulation & Algorithm

\[X_{k}=G_kX_{k-1}\]

where the matrix \(G_k\) is the system matrix at time k \(G=[A B]\)

\(G_k\) is updated based on a matrix \(P_k\) which is the autocorrelation matrix of all data to time k. \[P_k=(\sum_{i=1}^{k} X_iX^*_i)^{-1}\]

Initialization

  1. \(G_0=[A_d B_d]\) obtained in the offline DMD
  2. \(P_0=\tilde{\mathcal{\Omega}}_d\tilde{\mathcal{\Omega}}^*_d\) where \[ \tilde{\mathcal{\Omega}}_d=\begin{bmatrix} W^{-1}\mathcal{H_x}\\ \mathcal{H_u} \end{bmatrix} \]

Update

  1. Compute the gain \(\gamma\)

\[ \gamma=\frac{P_kX_k}{\rho+X^*_{k}P_kX_{k} } \] where \(\rho\) is a forgetting factor and \(X=\begin{bmatrix}\tilde{Z}_d\\ \mathcal{u}\end{bmatrix}\)

  1. Update \(P\) \[ P_{k+1}=\frac{1}{\rho}(P_k-\gamma (P_kX_k)^*) \]

  2. Update G \[ G_{k+1}=G_k+(X_{k+1}-G_kX_{k})\gamma^* \]

The eigenvectors and eigenvalues of matrix \(A\) can be extracted from \(G\) to monitor the system dynamics and drift.
